# {{name}}

A Kotlin service generated by `gauntlet new kotlin-service`, with a functional core:

- `domain`: values and rules. Errors are values (`Outcome`), nothing is mutable, money is held in minor units.
- `app`: use cases, written against ports such as `Ledger`.
- `infra`: implementations of the ports.

## Gauntlet

`.gauntlet/policy.gx` sets a high bar for every change, including agents' changes, and it starts in enforce mode:

- Tests, build configuration and the policy itself are protected. Editing them needs review, and in CI the protected files are put back to the base version before anything runs.
- `domain` must not depend on `app` or `infra`, and `app` must not depend on `infra`.
- Changed lines need 90% coverage, and changed code needs a mutation score of at least 80% that never drops.
- The core zone forbids `throw`, `var`, mutable collections, `!!`, `runCatching` and floating-point money.

Run `gauntlet check` before calling a change done, and `gauntlet explain` to see what the policy enforces.

```
./gradlew test
gauntlet check
```
