# Security

Gauntlet's job is to keep verification trustworthy, so a way around it is a
security issue: a change that weakens tests, policy or evidence and still
passes, a way to make Gauntlet read evidence it didn't produce, or a way for
pull request code to reach the trusted GitHub job.

Please report these privately, using **Report a vulnerability** on this
repository's [Security tab](https://github.com/matthewjones372/gauntlet/security),
rather than in a public issue. Include the policy, the change and what Gauntlet
decided, if you can.

Only the latest release is supported while Gauntlet is a release candidate.
