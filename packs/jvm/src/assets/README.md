# Vendored assets

- `tree-sitter-kotlin.wasm`: the Kotlin grammar from `@tree-sitter-grammars/tree-sitter-kotlin` 1.1.0 (MIT, see `LICENSE.tree-sitter-kotlin`), prebuilt for web-tree-sitter (ABI 14). Embedded in the binary, so detection never depends on the network or on files in the judged repository.
- `gauntlet.init.gradle`: the Gradle init script (ADR 0007).
